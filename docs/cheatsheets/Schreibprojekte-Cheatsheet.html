Start & Orientierung

TERMINAL · EINMALIG
cd /Pfad/zu/Schreibprojekte uv sync uv run manuskript config

uv sync richtet die Python-Umgebung ein. manuskript config zeigt Konfigurationsdatei, Standardquelle und Ausgabeordner an; es ändert nichts.

Projektstruktur 
MeinProjekt/
├── 01_Figuren/       # Story Bible
├── 03_Content/       # Manuskript
├── Metadaten/
├── lektorat/         # Berichte
└── docx/             # Exporte

REGEL Manuskriptdateien werden gelesen, aber von den Prüfungen niemals automatisch umgeschrieben.

DOCX exportieren

Gesamtes Manuskript

TERMINAL
uv run manuskript docx ../MeinProjekt

Exportiert alle Markdown-Dateien des Projekts in der vorgesehenen Reihenfolge als DOCX.

Eigenes Ausgabeziel

TERMINAL
uv run manuskript docx ../MeinProjekt \ --output docx/versuche

--output überschreibt für diesen Aufruf den konfigurierten Ausgabeordner.

Einzelne Markdown-Datei

TERMINAL
uv run manuskript single \ ../MeinProjekt/03_Content/101.md

Wandelt nur die angegebene Markdown-Datei um; das Original bleibt unverändert.

Direktaufruf: Skripte/convert-to-docx.sh ../MeinProjekt

Die drei Lektoratsebenen

Szene · Funktioniert diese Datei sprachlich, stilistisch und dramaturgisch?
TERMINAL
uv run manuskript lektorat-szene ../MeinProjekt/03_Content/205.md

Startet alle sieben Szenenmodule für genau eine Datei und schreibt einen separaten Bericht.

  1. Korrektorat
  2. Dialogformalia
  3. Stillektorat
  4. Dialoglektorat
  1. Szenenfunktion
  2. Perspektive
  3. Kontinuität

Der Szenenbericht enthält YAML-Metadaten zu Einstieg, Ziel, Konflikt, Dynamik, Wendung, Ausgang, Ende und Funktion.

Teil / Akt · Funktionieren Szenenfolge, Figurenentwicklung und Dramaturgie zusammen?
TERMINAL
uv run manuskript lektorat-teil ../MeinProjekt \ --start 200 --end 299 --label teil_2

Prüft den nummerierten Szenenbereich als zusammenhängenden Teil; --label benennt den Bericht.

Gesamtroman · Funktioniert das Manuskript als vollständiges Werk?
TERMINAL
uv run manuskript lektorat-gesamt ../MeinProjekt

Analysiert das vollständige Manuskript als Werk und muss bewusst gestartet werden.

OPTION --context PFAD bindet Figurenakten oder eine Story Bible ein.

So sieht ein Befund aus

Fundstelle → Diagnose → Relevanz → Begründung → Empfehlung → Querverweise

Erst wird die Wirkung beschrieben. Ersatzprosa folgt nicht ungefragt. Literarische Ellipsen, kurze Sätze und Dialogdichte dürfen Absicht sein.

Nachtlauf

Manuell starten; läuft im Hintergrund über alle konfigurierten Szenen in 03_Content.

TERMINAL · HINTERGRUND
Skripte/lektorat-nacht.sh ../MeinProjekt

Startet alle Datei- und Szenenprüfungen für 03_Content; Teil- und Gesamtlektorat sind nicht enthalten.

Neu prüfen

--force

Story Bible

--context PFAD

Fortschritt verfolgen

TERMINAL
tail -f ../MeinProjekt/lektorat/logs/ nachtlauf-YYYYMMDD-HHMMSS.log

tail -f zeigt neue Logzeilen fortlaufend an; Abbruch der Anzeige mit Ctrl+C.

  • Aktuelle Berichte werden übersprungen.
  • Einzelfehler stoppen den Lauf nicht.
  • Teil- und Gesamtlektorat bleiben bewusste Starts.

Konfigurationsdatei bearbeiten

.manuskript.json
{ "source": "03_Content", "output": "docx", "lektorat": { "base_url": "http://SERVER:11434", "model": "qwen3:8b" }, "korrektorat": { "base_url": "http://SERVER:8081", "language": "de-DE" }, "nachtlauf": { "exclude": ["050.md", "100.md"], "context": "01_Figuren" } }

Die JSON-Datei legt Quellordner, Ausgabeziel, Serveradressen, Modelle und Nachtlaufoptionen fest. manuskript config zeigt davon nur Pfad, Quelle und Ausgabe an.

Ollama-Port 11434 und LanguageTool-Port 8081 nur im Heimnetz oder über VPN freigeben.

Täglicher Schnellstart

MAC · AUF DEM HOMESERVER ANMELDEN
ssh schreibserver

Öffnet die Shell des Homeservers. Die Manuskripte bleiben auf dem NAS; der Server liest sie über NFS.

SERVER · ARBEITSORDNER UND KURZVARIABLEN
cd /home/sebastian/schreiben/Schreibprojekte
PROJEKT=/mnt/nfs/schreiben/Homestories
CONFIG=/home/sebastian/schreiben/config/Homestories.json
VOLLSTÄNDIGES SZENENLEKTORAT · BEISPIEL 101
uv run manuskript lektorat-szene "$PROJEKT/03_Content/101.md" --config "$CONFIG"

Der wichtigste Einzelbefehl: führt alle sieben Szenenmodule aus. Der Bericht landet unter lektorat/szene/; die Markdown-Datei bleibt unverändert.

Grundregel: Erst Diagnose und Befund lesen, dann selbst überarbeiten. Die Markdown-Datei bleibt bei allen Prüfungen unverändert.

Gezielte Einzelprüfungen

Rechtschreibung und Zeichensetzung

LANGUAGETOOL
uv run manuskript korrektorat "$PROJEKT/03_Content/101.md" --config "$CONFIG"

Findet mögliche Fehler bei Rechtschreibung, Grammatik und Zeichensetzung.

„sagte“ und Sprecherführung

DIALOG
uv run manuskript lektorat "$PROJEKT/03_Content/101.md" --config "$CONFIG"

Prüft, ob Sprecherzuordnungen nötig, überflüssig oder unklar sind.

Erklärungen nach H–L–X

EXPOSITION
uv run manuskript lektorat-hlx "$PROJEKT/03_Content/101.md" --config "$CONFIG"
H · Higgins: Abstrakt berichtete Information besser durch Dialog, sichtbare Handlung oder Reaktion vermitteln.
L · Leonard: Notwendiger, knapper und konkreter Satz – ebenso gelungener Dialog, Handlung und Orientierung – bleibt bestehen.
X · Erklärung: Satz erklärt nur noch einmal, was Dialog, Handlung oder Reaktion bereits eindeutig gezeigt haben; konkrete Doppelung muss benannt werden.

Adjektive und Adverbien

WORTARTEN
uv run manuskript lektorat-wortarten "$PROJEKT/03_Content/101.md" --config "$CONFIG"

Markiert auffällige Häufungen; literarische Verwendung ist nicht automatisch ein Fehler.

Wo liegt was?

OrtAufgabe
Mac / iPad / iPhoneObsidian: schreiben und bearbeiten
NASVaults unter /volume1/schreiben
NextcloudWebDAV-Zugang für Remotely Save
HomeserverOllama, LanguageTool und Lektorat
OpenProjectVersionen und Aufgaben für die Überarbeitung

Remotely Save: Endpunkt endet auf /schreiben; pro Vault genau einen Basisordner wie Homestories setzen. Vor Ordnerumbenennungen auf allen Geräten pausieren. OpenProject-Token nur auf dem Homeserver unter ~/.config/schreibprojekte/ speichern.

Konfiguration kurz prüfen

NUR ANZEIGE
uv run manuskript config --config "$CONFIG"

Zeigt Pfad der Konfiguration, Standardquelle und DOCX-Ausgabe. Erstellt und verändert keine Dateien.

Alle Szenen über Nacht prüfen

STAND 4 PRÜFEN · AUFGABEN FÜR STAND 5
homestories-lektorat start 4 5

Bindet den Nachtlauf per Prüfsummen an den abgeschlossenen Stand 4. Ein zweiter gleichzeitiger Lauf wird verhindert.

STATUS PRÜFEN
homestories-lektorat status

Zeigt, ob der Homestories-Nachtlauf gerade aktiv ist.

Fortschritt verfolgen

LOG LIVE ANZEIGEN
homestories-lektorat log

Beendet nur die Anzeige mit Ctrl+C; der Hintergrundlauf arbeitet weiter.

OPENPROJECT · ERST VORSCHAU
homestories-lektorat preview 4
OPENPROJECT · DANACH ÜBERTRAGEN
homestories-lektorat sync 4

Die Vorschau verändert nichts. Der Sync nutzt das nicht öffentliche Projekt Homestories und legt Version, Szenenaufgaben und zeilenspezifische Unteraufgaben idempotent an.

Bewusst getrennt: Der Nachtlauf automatisiert Datei-/Szenenprüfungen. Teil-/Akt- und Gesamtromanlektorat werden weiterhin gezielt gestartet.
