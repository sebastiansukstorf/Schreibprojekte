# Projektvorlage

Diese Vorlage beschreibt die empfohlene Ordnerstruktur für neue Schreibprojekte.

## Ordner

- 00_Planung/
- 01_Figuren/
- 03_Content/
- Metadaten/
- docx/
- lektorat/szene/
- lektorat/teile/
- lektorat/gesamt/

Optionale projektspezifische Bereiche:

- 05_Agenturen/
- 06_Lesungen/
- 09_Images/
- 10_Social_Media/

Allgemeine Methoden und technische Werkzeuge werden nicht in das Projekt kopiert. Sie verbleiben zentral in `Schreibprojekte`.
